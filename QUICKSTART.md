# Symbiont — Quick Start

**Персональный автономный агент на Android. 5 минут без LLM. 40 минут с локальным мозгом.**

Без ПК. Без облака. Без API-ключей.

---

## Что нужно

- Android 8+
- 2 ГБ свободного места
- 10-40 минут

---

## Шаг 1. Установи Termux и Termux:API

**Из F-Droid** (не из Play Store — там подделка):

1. Открой `f-droid.org` в браузере.
2. Скачай и установи **F-Droid**.
3. В F-Droid установи **Termux**.
4. В F-Droid установи **Termux:API**.
5. Открой **Termux:API** один раз — дай все разрешения (микрофон, уведомления, местоположение, файлы).

---

## Шаг 2. Установи Python и инструменты

Открой **Termux**. Вводи **по одной команде**:

```bash
pkg update && pkg upgrade -y
```

```bash
pkg install python termux-api git wget -y
```

```bash
termux-setup-storage
```

Когда спросит разрешение — **разреши**.

**Проверка:**

```bash
termux-tts-speak "Hello"
```

Должен услышать голос. Если услышал — **всё работает**.

## Шаг 5. Локальный LLM (мозг)

**Долго — 20-40 минут.** Телефон — **на зарядку**.

```bash
pkg install cmake clang binutils -y
```

```bash
cd ~
```

```bash
git clone https://github.com/ggerganov/llama.cpp
```

```bash
cd llama.cpp
```

```bash
cmake -B build
```

```bash
cmake --build build --config Release -j4
```

**Ждёшь 20-40 минут.** Телефон **нагреется**. Это **нормально**.

Когда закончится — **скачай модель**:

```bash
mkdir -p ~/models
```

```bash
cd ~/models
```

```bash
wget https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/qwen2.5-1.5b-instruct-q4_k_m.gguf
```

**~1 ГБ.** Скачивание — 5-10 минут.

**Проверка:**

```bash
ls -lh ~/models/
```

Должен быть файл **~1 ГБ**.

---

## Шаг 6. Запусти LLM + Symbiont вместе

**Сессия 1** — запусти мозг:

```bash
cd ~/llama.cpp
```

```bash
./build/bin/llama-server -m ~/models/qwen2.5-1.5b-instruct-q4_k_m.gguf --port 11434
```

Ждёшь: `listening on http://127.0.0.1:11434`

**Не закрывай эту сессию.**

**Сессия 2** — свайп влево в Termux → **New session**. Там:

```bash
cd ~/symbiont
```

```bash
python symbiont_core.py
```

Внутри Symbiont:

```
llm on http://localhost:11434 qwen2.5
```

Должно быть:

```
LLM: http://localhost:11434 / qwen2.5
```

**Тест:**

```
say что ты думаешь о свободе
```

Symbiont **ответит осмысленно**. Не «Запомнил». А **подумает**.

**Голос:**

```
speak Привет, я Сим
```

**Услышишь** — Symbiont **скажет**.

**Слух:**

```
listen
```

**Скажи** что-то. Symbiont **услышит**.

## Команды

| Команда | Что делает |
|---|---|
| `say <текст>` | Поговорить с Symbiont |
| `speak <текст>` | Symbiont говорит голосом |
| `listen` | Symbiont слушает микрофон |
| `memory` | Что помнит |
| `recall` | Что знает о тебе |
| `night` | Разбор дня |
| `morning` | Утренний отчёт |
| `llm on <url> <model>` | Подключить LLM |
| `status` | Полный статус |
| `help` | Все команды |
| `exit` | Выход |

## Решение проблем

**`termux-tts-speak: command not found`**
→ Установи приложение **Termux:API** из F-Droid, открой его один раз.

**`Permission denied` при `listen`**
→ Открой **Termux:API** → дай разрешение на **микрофон**.

**LLM-сервер не запускается**
→ Проверь модель: `ls -lh ~/models/`
→ Файл должен быть ~1 ГБ.

**`llm on` пишет «недоступен»**
→ Проверь, что LLM работает в **Сессии 1**.
→ Тест: `curl http://localhost:11434/v1/models`

**Память не сохраняется между запусками**
→ Проверь, что папка `~/symbiont/symbiont_data/` **существует**.
→ **Не удаляй** её.

**Сборка llama.cpp падает**
→ Попробуй `-j2` вместо `-j4` (меньше памяти).
→ Или перезапусти сборку — она **продолжит** с места остановки.
