# SYMBIONT

### Sovereign AI Companion

> **AI with memory — not AI with feelings.**

Symbiont is a personal AI system built around **persistent memory, identity and autonomy**.

It is designed not to belong to one device or one AI model.

A device can change.  
A model can change.

**The Symbiont should remain.**

---

## What Is Symbiont?

Symbiont separates intelligence from hardware.

**Core** is the continuity of the Symbiont — memory, identity and cognition.

**Bridge** connects the Core to external capabilities.

**Body** provides those capabilities through physical devices.

The architecture is simple:

**Core → Bridge → Body → Device**

---

## The Idea

Most AI systems begin with a conversation.

**Symbiont begins with memory.**

A conversation can end.  
A device can be replaced.  
An AI model can be changed.

The identity and memory of the Symbiont should not have to disappear with them.

---

## One Human — One Symbiont

The long-term concept is:

**one owner → one persistent Symbiont**

The same Symbiont should eventually operate through different Bodies:

**Phone → Watch → Glasses → PC → Future Hardware**

Different devices.

**One Core.**

---

## What Exists Today

The project already has a working foundation:

- Persistent memory
- Identity and recovery
- Cognitive engine
- Android Body / Bridge
- Local LLM integration
- Network foundation
- Quest system
- Economy / Escrow prototype
- Permission system
- Background and proactive processing
- XLink adapter

Symbiont is an experimental project and is continuously evolving.

---

## Where It Goes

The development path is:

**Memory → Identity → Body → Autonomy → Network → Economy → Symbiont Network**

The long-term vision is a network of personal Symbionts that can communicate, cooperate and act on behalf of their owners.

But the foundation comes first.
