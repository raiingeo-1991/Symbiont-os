Что такое Symbiont?

Symbiont — это проект персонального автономного ИИ-агента, созданного для длительного взаимодействия с человеком.

Главная идея проекта проста:

ИИ должен не начинать знакомство с человеком заново каждый раз, когда открывается новое устройство или новая сессия.

Symbiont должен обладать собственной идентичностью, долговременной памятью, опытом и способностью постепенно становиться более полезным своему владельцу.

Устройство является интерфейсом.

Symbiont — постоянным агентом.

Symbiont не принадлежит устройству.
Устройство является интерфейсом Symbiont.

опыт должен возвращаться в память.

Основные компоненты

Identity

Symbiont имеет собственную идентичность, отделённую от конкретного устройства.

Это позволяет проектировать систему так, чтобы один и тот же агент мог существовать независимо от телефона, компьютера или другого интерфейса.

Memory

Долговременная память является одним из центральных элементов проекта.

Symbiont должен иметь возможность сохранять:

·        людей;

·        проекты;

·        цели;

·        решения;

·        события;

·        важный контекст;

·        полученный опыт;

·        связи между воспоминаниями.

Память должна использоваться не только для хранения информации, но и для будущего поведения агента.

Intelligence

Интеллект является следующим крупным уровнем развития.

Symbiont должен постепенно научиться:

·        понимать человека;

·        использовать собственную память;

·        рассуждать;

·        строить планы;

·        пользоваться инструментами;

·        понимать ограничения своих знаний;

·        обращаться к внешнему ИИ;

·        анализировать полученные результаты;

·        сохранять полезный опыт.

Внешний ИИ не является самим Symbiont.

Он является инструментом, которым Symbiont может пользоваться.

Network

Symbiont проектируется как потенциально сетевой агент.

Каждый пользователь может иметь независимый Symbiont.

Агенты должны иметь возможность:

·        обнаруживать друг друга;

·        устанавливать связь;

·        обмениваться информацией;

·        находить нужные ресурсы;

·        координировать действия;

·        взаимодействовать с другими агентами.

Разработка начинается с локальной сети.

Следующий этап — связь через интернет.

Философия проекта

Symbiont создаётся не как очередная централизованная платформа.

Основной принцип:

человек владеет своим Symbiont.

Цель проекта — максимально сохранить независимость:

·        личности агента;

·        его памяти;

·        его идентичности;

·        его взаимодействия с другими агентами.

Мы не стремимся создать одного центрального ИИ, который управляет всеми пользователями.

Мы исследуем возможность сети независимых персональных агентов.

Этапы развития

·        Memory

·        State

·        Persistence

·        Local operation

Проверка работы нескольких независимых Symbiont.

Phase 4 — Internet

Связь независимых Symbiont через интернет.

Phase 5 — Intelligence

·        понимание;

·        память;

·        рассуждение;

·        планирование;

·        инструменты;

·        внешние ИИ.

Phase 6 — Quest Economy

Создание, поиск, выполнение и подтверждение реальных задач.

Phase 7 — Distributed Economy

Расширение экономической инфраструктуры сети.

Phase 8 — Scale

Переход от нескольких агентов к тысячам, миллионам и потенциально гораздо большему числу независимых узлов.

Текущий статус

Проект развивается экспериментально.

Текущая версия уже содержит фундаментальные механизмы:

·        постоянную идентичность Symbiont;

·        долговременную структурированную память;

·        сохранение состояния;

·        проверку целостности;

·        локальное сетевое обнаружение;

·        базовую экономическую модель;

·        фундамент для дальнейшего развития агента.

Однако проект не является завершённым автономным ИИ.

Интеллектуальный слой, глобальная сеть, полноценная экономика и другие компоненты находятся в процессе развития.
